# Jogo Nutri Drop

### 2026-01

## Visão Geral

O **Nutri Drop** é um jogo digital desenvolvido em JavaScript com o uso da biblioteca **Phaser**, voltado para a criação de experiências interativas em 2D diretamente no navegador.

O projeto foi desenvolvido como parte do **Laboratório Experimental** do curso de **Sistemas de Informação da ESPM**, com o objetivo de aplicar conceitos de programação, desenvolvimento de jogos, organização de projetos web e trabalho em equipe.

A aplicação utiliza uma estrutura simples de projeto web, composta por HTML, JavaScript e a biblioteca Phaser. O arquivo `index.html` é responsável por carregar a página do jogo, importar a biblioteca `phaser.js` e iniciar o código principal localizado em `src/main.js`.

## Objetivos do Projeto

O objetivo principal do projeto é desenvolver um jogo funcional utilizando a biblioteca Phaser, explorando conceitos de lógica de programação, interatividade e desenvolvimento front-end.

Entre os principais objetivos do projeto estão:

- Desenvolver um jogo 2D executável no navegador.
- Utilizar o Phaser como engine principal do projeto.
- Trabalhar com estrutura de cenas, elementos visuais e lógica de jogo.
- Aplicar conceitos de HTML, CSS e JavaScript.
- Organizar os arquivos do projeto de forma clara e funcional.
- Praticar o desenvolvimento colaborativo em grupo.
- Criar uma experiência interativa relacionada ao tema proposto pelo jogo.

## Mais Informações

O projeto utiliza a biblioteca **Phaser 3** para criação e renderização do jogo no navegador.

Configurações identificadas no projeto:

- **Nome do jogo:** Nutri Drop
- **Largura da tela:** 1280 pixels
- **Altura da tela:** 720 pixels
- **Engine:** Phaser
- **Versão do Phaser:** 3.88.2
- **Tipo de projeto:** jogo web em JavaScript
